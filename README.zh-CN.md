<a id="workflow"></a>
## 从剧本到成片

沿着连贯的制作流程推进，每个阶段为下一阶段准备素材；需要调整时，也可以返回前面的阶段继续修改。

1. **导入并整理剧本**，创建项目和剧集。
2. **借助 AI 改写和润色**故事内容与对白。
3. **建立全剧资产库**，管理角色、场景、道具和角色音色参考。
4. **规划每集内容**，设置导演意图、时长规格、分镜描述和视频提示词。
5. **生成并检查分镜视频**，跟踪任务进度，再合并片段并导出本集。

<a id="features"></a>
## 为连贯制作而设计

- 在同一项目中管理剧本、资产、剧集和任务记录。
- 在全剧范围内复用角色、场景和道具参考素材。
- 为角色绑定音色参考；角色出现在分镜中时，系统会自动带入该参考音频。
- 设置项目级文本、图片和视频模型；有特殊情节时可按集调整导演规划。
- 生成视频前检查导演规划是否符合视频模型的限制。
- 使用 AI Agent 辅助剧本改写、资产提取、分镜拆解和提示词生成。
- 支持简体中文、English、日本語和한국어界面。
